Información para las personas visitantes

Aviso de privacidad

Última actualización: 6 de noviembre de 2026.

1. Quién es responsable

Este sitio se identifica comercialmente como Impresiones 3D. El nombre legal y el RUC del titular no fueron proporcionados al preparar esta página y deben confirmarse con el titular antes de publicarla. No se inventan una razón social ni datos de identificación.

Para consultas sobre esta página, privacidad o solicitudes sobre datos personales, escribe al WhatsApp +51 919 161 560.

2. Qué información recopila esta página

El sitio no tiene formularios, registros de cuenta, pagos, listas de correo ni espacios para cargar archivos. No pedimos nombre, correo, dirección, datos de pago ni documentos para poder visitar estas páginas.

Si eliges iniciar una conversación, WhatsApp puede recibir los datos que decidas enviar, como tu número, mensaje, fotografías o descripción de una idea. Envía únicamente la información necesaria para consultar el trabajo. No envíes documentos de identidad ni datos financieros sensibles por la página.

Cuando abres un enlace externo a WhatsApp, TikTok o Facebook, sales del sitio y el proveedor correspondiente procesa la visita según sus propios avisos y condiciones. Los enlaces no cargan videos, píxeles ni perfiles de esos servicios dentro de esta página.

3. Para qué se utiliza la información

La información que compartas por voluntad propia por WhatsApp se utilizará para responder tu consulta, conversar sobre la posibilidad de fabricar un artículo, preparar una cotización y coordinar un trabajo que hayas aceptado. No se utiliza esta web para publicidad dirigida, venta de listas de contactos ni decisiones automatizadas.

El responsable no tiene en este sitio un formulario o una herramienta independiente de gestión de clientes. WhatsApp es un servicio externo y conserva o trata mensajes conforme a las condiciones de esa plataforma y a la configuración de los participantes.

4. Alojamiento y archivos

Al publicarse en GitHub Pages, el proveedor de alojamiento recibe las solicitudes técnicas necesarias para entregar la página. El sitio no integra de manera intencional una herramienta de analítica ni instala cookies publicitarias. El proveedor de alojamiento puede procesar datos técnicos de acceso de acuerdo con sus propias políticas.

Los estilos, ilustraciones y código de esta página se sirven desde el propio sitio; no se solicitan fuentes o bibliotecas a redes externas mientras navegas.

5. Conservación y seguridad

El sitio no crea una base de datos de consultas. La conversación que decidas iniciar se mantiene en WhatsApp, que es un servicio independiente. Evita enviar información personal que no sea necesaria. Si una consulta no lleva a un trabajo, puedes escribir para solicitar que el titular no vuelva a contactarte con mensajes promocionales.

Ninguna página o servicio puede garantizar seguridad absoluta. Mantén actualizada tu aplicación y no compartas códigos de acceso, contraseñas ni información financiera.

6. Derechos sobre tus datos (ARCO)

No hay cuentas de usuario en esta página que necesites cerrar. Si compartiste información directamente con el titular, puedes escribir para consultar cómo solicitar acceso, rectificación, cancelación o eliminación u oposición sobre esa información. Indica de forma clara qué derecho quieres ejercer y a qué conversación te refieres. Solo podrían pedirte información adicional cuando resulte necesaria para identificar la solicitud.

La información y los derechos se atienden conforme a la normativa peruana aplicable. La solicitud debe dirigirse al responsable, no a través de un formulario automatizado de este sitio. El titular revisará cómo atenderla y cualquier verificación necesaria.

7. Menores de edad

Este sitio no está diseñado para recopilar datos de menores. Si eres menor, pide a tu madre, padre o tutor que te acompañe y autorice antes de enviar mensajes, fotos o información para solicitar un trabajo. No envíes tus datos de contacto o domicilio sin el permiso de una persona adulta responsable.

8. Solicitar que no te contacten

No hay suscripciones, newsletter ni lista de correos de esta página. Si ya iniciaste una conversación y no quieres recibir más mensajes promocionales del titular, utiliza el siguiente enlace y solicita expresamente que no te vuelvan a contactar con promociones.
